---
title: Sysops
description: Always-on Netdata infrastructure monitoring with an optional SigNoz diagnostics stack.
---

Sysops owns operational visibility without becoming a workflow dependency. A monitoring outage must
not block ingestion, analytics, OCR, BI, or durable Airflow task logging.

## Runtime ownership

| Runtime                            | Mode                                      | Repository owner                                                         |
| ---------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------ |
| Netdata Agent                      | Always on                                 | `sysops/netdata/` Compose, collectors, health, StatsD, and deploy script |
| SigNoz and OpenTelemetry Collector | Stopped; started manually for diagnostics | `sysops/signoz/` Foundry, Collector, Terraform dashboards, and alerts    |

Netdata uses one digest-pinned upstream container on the OCI services host. It is unclaimed,
loopback-bound, accessible through Cloudflare Access, and configured entirely from reviewed files.
The deployment smoke test verifies native collectors, sensitive Function access, local MCP, Health
mode, persistent mounts, StatsD isolation, and chart units.

## Native collection scope

- Host CPU, load, memory, PSI, disk, filesystem, network, OOM, and selected systemd units.
- Docker engine state and health plus workload cgroup CPU, memory, and I/O.
- Metadata PostgreSQL using the least-privilege `lakehouse_monitor` role.
- Origin HTTP health and public certificate validity for the private applications.
- A bounded Airflow StatsD allowlist for scheduler, executor, DAG-run, and task duration signals.
- Native Live Views, journal search, PostgreSQL Functions, ML anomaly detection, Health, and local
  MCP.

Generic Apps charts, broad service auto-discovery, Cloud claiming, streaming, exporting backends,
OTLP, and unrestricted StatsD chart creation stay disabled.

## Data and notification policy

Netdata retains operational metrics in size-bounded DBEngine tiers. Its history is disposable and
is not a backup. Airflow task logs remain in S3, while service logs remain in Docker and systemd
journal.

Native alert evaluation and history are active, but every external notification transport is
disabled until a receiver and owner are explicitly approved. SigNoz collects no metrics, logs, or
traces while stopped.

See [Observability](/docs/operations/observability) for access, units, deployment, retention,
upgrades, alert tuning, and troubleshooting.
